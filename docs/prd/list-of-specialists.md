# PRD: Сторінка лікарів по спеціальності

**Тікет:** HELSI-5  
**Дата:** 2026-06-02  
**Статус:** Очікує підтвердження

---

## 1. Проблема

Натискання на картку спеціальності в `SpecialtiesSection` на головній сторінці переходить на `/doctors?specialty=...`, але маршрут `/doctors` не існує в Router — користувач потрапляє на 404. Потрібна повноцінна сторінка, яка показує лікарів відповідної спеціальності.

---

## 2. Мета

Надати користувачеві можливість переглянути список лікарів конкретної спеціальності після вибору з `SpecialtiesSection`.

---

## 3. User stories

- Як користувач, я хочу натиснути "Дерматолог" на головній і побачити список всіх дерматологів.
- Як користувач, я хочу бачити ключову інформацію про лікаря (фото, ім'я, досвід, адреса, графік, ціна) без переходу в профіль.
- Як користувач, якщо лікарів немає — я хочу бачити зрозуміле повідомлення і спосіб повернутись.

---

## 4. Scope

### В скоупі
- Нова сторінка `DoctorsBySpecialty`
- Горизонтальні картки лікарів (стиль helsi.me)
- Hero-банер з іконкою, назвою спеціальності, breadcrumbs і кількістю знайдених
- Empty state: іконка спеціальності + текст + кнопка "Обрати іншу спеціальність"
- Маршрут `/doctors/:specialty`
- Переключення маршрутизації в `SpecialtiesSection` з query param на path param
- Переклади (uk + en)

### Поза скоупом
- Фільтрація / сортування всередині сторінки
- Пагінація
- Booking flow ("Записатись")
- Рейтинги лікарів

## 5. Дизайн

### 5.1 URL

```
/doctors/:specialty
```

Приклад: `/doctors/dermatologist`

### 5.2 Hero-банер (верх сторінки)

```
┌─────────────────────────────────────────────────────┐
│  🏠 Головна  /  Дерматологи                         │
│                                                      │
│  🟠  Дерматологи                                    │
│      Знайдено 3 спеціалісти                          │
└─────────────────────────────────────────────────────┘
```

- Колір фону і колір іконки беремо з масиву `SPECIALTIES` в `SpecialtiesSection`
- Breadcrumb: "Головна" → назва спеціальності (клікабельна "Головна")
- Лічильник: динамічний, з `doctorsList` з ProfileContext

### 5.3 Картка лікаря (горизонтальна)

```
┌──────────────────────────────────────────────────────────┐
│  [Аватар]  Іванов Іван Іванович           [Переглянути]  │
│  72×72     🏷 Дерматолог · 5 р. досвіду               │
│            📍 вул. Хрещатик, 1                          │
│            🕐 Пн Вт Ср  09:00 – 18:00                  │
│            💰 500 ₴ за консультацію                    │
└──────────────────────────────────────────────────────────┘
```

Поля картки (всі з `IDoctorProfile`):
| Поле | Відображення |
|---|---|
| `photoURL` | Avatar 72×72 |
| `name` + `lastName` | Заголовок |
| `specialty` | Chip (колір по спеціальності) |
| `experience` | `{years} р. досвіду` (якщо є) |
| `address` | 📍 (якщо є) |
| `days` + `startTime` + `endTime` | 🕐 відсортовані дні + години |
| `fee` | 💰 ₴ (якщо є) |

Кнопка "Переглянути профіль" веде на `/profile/:userID`.

Hover: підсвітка бордером кольором спеціальності + легка тінь.

### 5.4 Empty state

```
        ╔══════════════════════════════╗
        ║                              ║
        ║    [велика іконка спец.]     ║
        ║                              ║
        ║  Дерматологів поки немає     ║
        ║  Спеціалісти з'являться      ║
        ║  найближчим часом            ║
        ║                              ║
        ║  [← Обрати іншу спеціальність]║

```

- Іконка — та сама що в `SpecialtiesSection`, 80px, колір спеціальності на фоні `bgColor`
- Кнопка повертає на головну `/`

## 6. Технічна реалізація

### 6.1 Нові файли

```
src/pages/DoctorsBySpecialty/
  DoctorsBySpecialty.tsx      — основна сторінка
```

### 6.2 Зміни в існуючих файлах

| Файл | Зміна |
|---|---|
| `src/routes.ts` | Додати `doctorsBySpecialtyRoute = '/doctors/:specialty'` |
| `src/Router.tsx` | Додати `<Route path={doctorsBySpecialtyRoute} ...>` з `ProtectedRoute` + `MainLayout` |
| `src/pages/Home/components/SpecialtiesSection.tsx` | Змінити navigate з `?specialty=` на `/${key}` |
| `src/languages/en.json` | Нові ключі (div. 6.3) |
| `src/languages/uk.json` | Нові ключі (div. 6.3) |

### 6.3 Нові ключі перекладу

| Key | EN | UK |
|---|---|---|
| `specialty-doctors-found` | `{count} specialist(s) found` | `Знайдено {count} спеціалісти(ів)` |
| `specialty-no-doctors` | `No {specialty} available yet` | `{specialty} поки немає` |
| `specialty-no-doctors-desc` | `Specialists will appear soon` | `Спеціалісти з'являться найближчим часом` |
| `specialty-back-btn` | `← Choose another specialty` | `← Обрати іншу спеціальність` |
| `breadcrumb-home` | `Home` | `Головна` |

### 6.4 Дані

Дані беруться з `ProfileContext.doctorsList` — фільтрація по полю `specialty === specialtyParam`.  
Масив `SPECIALTIES` з `SpecialtiesSection` потрібно винести в окремий файл `src/constants/specialties.ts` або `src/config/specialties.ts`, щоб і `SpecialtiesSection`, і `DoctorsBySpecialty` мали доступ до кольорів та іконок.

### 6.5 Маршрутизація

`SpecialtiesSection` змінює:
```ts
// було
navigate(`${listOfDoctorsRoute}?specialty=${specialtyKey}`);

// стане
navigate(`/doctors/${specialtyKey}`);
```
